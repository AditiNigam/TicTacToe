# 🎮 Tic Tac Toe

An interactive Tic Tac Toe web game built using HTML, CSS, and JavaScript. Play against the computer or challenge a friend in two-player mode with a clean and responsive interface.

## ✨ Features

- 🤖 Player vs Computer mode
- 👥 Two-player mode
- 🏆 Automatic winner detection
- 🤝 Draw detection
- 📊 Score tracking
- 🔄 Restart game and reset scores
- 🎨 Clean and responsive user interface

## 🛠️ Technologies Used

- **HTML** – Structures the game interface.
- **CSS** – Styles the board and user interface.
- **JavaScript** – Implements game logic, player turns, computer moves, and result detection.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a web browser.
